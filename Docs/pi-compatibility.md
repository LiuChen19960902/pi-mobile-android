# Pi 支持边界

Pi Mobile 通过网关使用 Pi SDK，提供手机界面；它不镜像正在运行的 Pi 终端。支持范围以网关锁定的 SDK、已实现的协议和客户端投影为准。当前配套网关锁定的依赖为 `@earendil-works/pi-coding-agent 1.3.0`，不能用另一版本 CLI 的表现代替兼容性验证。

## 按公开契约接入

本项目对齐 Pi 的通用消息、工具和会话语义，不按第三方扩展或 Package 的名字逐个适配。扩展若通过已支持的 Pi 接口输出消息或工具结果，手机应按同一套规则处理；依赖终端界面、私有事件或进程内状态的部分不在这个承诺内。

| 能力 | 接入约定与边界 |
| --- | --- |
| 会话、用户/assistant 消息、思考、工具调用与结果 | 依据 SDK 事件和会话历史呈现，不依赖工具来自内置实现还是扩展。输入受理、开始运行、排队和运行结束应分开处理 |
| 模型、思考档位、模型范围、会话树 | 使用 Pi 对应的配置和会话语义；手机已有入口不要求复制 CLI 快捷键。现有树界面不代表全部 TUI 树操作都已提供 |
| Skills、自定义 Prompt | 使用 SDK 发现与展开规则。Package 提供的资源也可被发现；Package 是资源分发形式，不是统一禁止的功能类别。输入处理器可能先消费命令，候选存在不保证一定启动模型 |
| `@` | 对齐 CLI 编辑器里的文件/目录补全，插入路径引用；不等同于启动参数 `pi @file` 的文件内容读取 |
| 可见的 `custom_message` | 仅 `display=true` 时可见（缺省或 false 均隐藏），以通用通知样式展示文本内容；不执行扩展自定义 TUI renderer |
| `custom` 持久化条目 | 默认视为扩展内部数据，不直接渲染 JSON、推测业务状态或当成错误消息。它与 `custom_message` 不同 |
| 工具进度与嵌套工具 | 实时调用按 SDK 调用 ID、父调用关系和结束事件配对；普通顶层最终结果以 `toolResult` 为准，嵌套调用用 `end` 收尾。partial 进度尚不提供专门 UI；历史没有独立子调用结果时不编造恢复数据 |
| 扩展弹窗、通知与 widget | 当前网关没有提供扩展 UI 桥接。官方 RPC 的部分 UI 能力在技术上可以另行接入，但本版没有这个能力 |
| 插件私有后台任务面板 | 不读取插件私有文件、事件总线或管理器来拼专用面板；现有消息流没有传递的后台状态，手机无法据此还原 |

因此，“在 Pi 终端可运行”不足以保证手机具备相同的全部功能。需要核对它是否依赖 TUI，以及输出是否经过手机已接入的公开契约。

## 当前实现的限制

网关通过 SDK 创建 `AgentSession`，调用 `bindExtensions({mode: "rpc"})`，但没有传入 `uiContext`。SDK 在这个用法下使用 no-op UI：选择/输入返回取消值，确认返回否，状态栏/widget 不显示。这个绑定方式不等于已经实现官方 `extension_ui_request/response` 协议。

`prompt-disposition-v1` 网关提供输入回执及权威活动快照，客户端分开记录等待回执的输入与实际运行；SDK 未给出处置值时不猜测。旧网关未声明能力时保留原路径，不能由新手机包单方面补齐回执语义。

可见文本的实时和历史投影使用条目 ID 对消，同文的不同条目仍保留；SDK 同批事件与新增条目不能一一对应时省略未知身份，不按正文或时间猜测。旧网关没有历史来源字段的消息只能保守显示其可见文本，不能凭 `customType` 识别原生压缩。

普通工具调用、结果和原生 assistant 错误使用通用路径。插件只写内部数据或吞掉原生错误时，手机不猜测还原其提示，也不由此获得插件私有后台状态。

手动压缩调用宿主 SDK 的 `session.compact()`，会经过宿主资源加载与压缩钩子；本项目不另外实现某个第三方压缩器。

当前输入回执没有逐条请求 ID，同一连接、同一会话异常重复的合法回执仍有归属限制。普通请求的关联与非法回执守卫不能消除这项协议限制。

官方 RPC 支持部分对话框、通知和文本 widget；依赖终端的组件仍有限制，组件工厂不能直接搬到手机。参见 [Pi 扩展文档](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/extensions.md)和 [RPC Extension UI](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/rpc-extension-ui.md)。这些链接指向上游当前文档，具体接入仍须核对网关锁定版本。
