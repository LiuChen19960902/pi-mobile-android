# Agent Note: 会话树由网关按 Pi 规则投影，手机不计算布局

Status: implemented

## 问题

Pi 会话是一棵树：分叉、切分支和标签都基于条目的 `parentId`。手机要在窄屏上显示这棵树并支持跳转。早期客户端自己算布局，经历了 depth × 缩进（长链一路右漂到屏幕外，看似空树）、分支代数、泳道几轮方案，每次都与 Pi 的 `/tree` 显示不一致；树还曾因被过滤的中间条目断链，被切成几十个根。

## 决定

### 投影在网关完成

- 网关在投影时只保留 user / assistant 节点（纯工具 assistant 过滤，当前叶子和中止 / 出错的 assistant 例外），把 `parentId` 重映射到**最近的可见祖先**。被过滤的 toolResult、model_change 等中间条目不会断链。可见性过滤与分叉计数必须同口径：分叉只看可见孩子。
- 每行的 `prefix` 按 Pi `tree-selector.js` 的规则计算：每级 3 个字符，只有分叉才缩进，单链平铺；穿透竖线表示上一级还有后续兄弟。手机用等宽字体直接拼接 `prefix`，不做布局计算。
- 宣告 `tree-view-v1` 的网关在完整树上执行 Pi 的过滤、搜索、折叠，再生成 prefix、显示文本、活动路径和选择。Pi SDK 先对完整树做“活动分支优先”排序再过滤，隐藏的祖先仍影响可见节点顺序；搜索普通消息只取前 200 个字符。
- 截断时活动路径整条保留，其余按时间戳取最近，保持展示顺序；不按数组尾部截断，因为 Pi 把活动分支排在同级最前，切尾会把当前对话整支切掉。旧接口最多返回最近 400 个节点。
- 深单链用显式栈展平为扁平 wire 结构，不递归、不序列化嵌套 JSON（3400 多条时曾爆栈）。
- 纯图 user 消息没有文本块，网关用 `(image)` 占位，否则树行只剩角色标签。

### 手机侧展示

- 有可见孩子的展开根节点 `foldable=true` 但 `prefix` 可能为空，客户端要补出折叠标记，否则唯一的折叠按钮会消失。折叠点击附在前缀上。
- 为接近桌面 HTML 导出的观感，客户端在每个可见 user 之后、`parentId` 连续的一段内补画组内 `├─` / `└─`（`treeDisplayPrefixes`）。真实分叉和折叠字符原样保留，每行从 wire 原 prefix 计算，不从上一行的显示结果累积；缺 user 或断链时保持原样。这是装饰线，不改变网关拓扑、节点身份或折叠语义。
- 网关与客户端的标签格式要成对修改，否则角色标签与正文会重复或错位；客户端不做旧格式兼容解析。

### 浏览、动作与跳转

- Tree 页中“浏览选中”与 SDK 的 active leaf 分开：点行只打开动作卡，只有“跳到此处”才调用 `switch-branch`。
- 宣告 `tree-actions-v1` 的网关提供条目全文复制（按 Pi `getEntryCopyText` 取原文，超预算时明示未复制，不用 preview 冒充全文）和追加标签。复制与标签各只有一个在途请求，按会话 + 条目关联；导航、重新配对和重置时清掉旧发布态，避免旧回执在新会话写剪贴板或关闭另一节点的卡片。
- `appendLabelChange` 会推进运行时叶子。网关只让**标签写入登记的钉子**跟随其运行时后代（之后自然追加的回答或压缩条目），普通手动跳转的钉子保持原位置，否则“浏览旧分支并停在原处”的语义会被破坏。
- 流式中切分支时，网关先读出 steering / followUp 文本，再 abort 并导航，返回的排队文本由客户端合并进草稿；压缩进行中拒绝切换。`navigateTree` 固定 `summarize=false`。
- 跳转后的编辑器回填规则见 [输入草稿的归属与回填](2026-10-09-composer-draft-ownership.md)。

## 考虑过的方案

**客户端按 depth × 缩进布局。** 长会话节点被推出屏幕。

**分支代数、泳道布局。** 与 Pi 显示不一致，每种布局都需要客户端维护一套拓扑计算，已整体删除。

**“父不在可见列表就当根”。** 真实会话中大量节点的父是被过滤的 toolResult，树被切碎、竖线不连。

## 影响

- 树的显示与 Pi `/tree` 保持一致，客户端只负责渲染和组内装饰线。
- 极深分叉时前缀会占满单行宽度，正文可能被挤到不可见，前缀没有宽度护栏；Tree 页允许横向滑动来查看更多内容。
- 新客户端连旧网关时可能出现双重角色前缀，升级网关或刷新树后恢复。

## 核对入口

- 网关 `src/wire.ts` 的 `toWireTreeNodes`、`buildTreePrefix`、`trimTreeNodes`；`src/pi-runtime.ts` 的叶子维护与标签钉子；协议 `PROTOCOL.md` §4.26–4.27。
- Pi SDK：`dist/modes/interactive/components/tree-selector.js`（前缀规则真源）、`getEntryCopyText`、`navigateTree`。
- 客户端 `treeDisplayPrefixes`、`treeRowPrefix`；`wire.test.ts` 的 `toWireTreeNodes` 用例。
