# Agent Note: 会话隐藏与恢复由本地记录决定

Status: implemented

## 问题

用户可以在手机上隐藏会话或整个目录来整理列表。旧实现用“隐藏 ID 与当前会话列表的交集”生成恢复项，隐藏目录也要求当前列表中存在对应 cwd。冷启动尚未取回目录、离线或只收到部分目录时，隐藏规则仍在，恢复入口却消失了，看起来像持久化丢失。

## 决定

- 隐藏是只影响手机列表的客户端功能，不映射为网关删除请求。Pi 原生会话选择器的删除会移入系统回收站或 `unlink`，没有对应的隐藏 / 恢复接口。
- 记录由 `AndroidGatewayPreferences` 的 `gateway.hidden_sessions`、`gateway.hidden_directories` 持久化；hide / restore 先更新界面，再用 DataStore 事务读改写。
- “已隐藏”入口、计数、恢复列表、空列表提示和恢复完毕后的关闭条件都只由保存的会话 ID / 目录路径决定。网关会话列表只补充标题等展示信息。
- 未取到标题时保留完整会话 ID 作为恢复参数，显示占位标题和短 ID；单项恢复和全部恢复都不需要连上网关。目录组即使当前列表中没有该 cwd，也允许移除隐藏规则。

## 考虑过的方案

**清空黑名单来修复入口消失。** 会破坏用户保持列表整洁的选择。

## 影响

- 恢复列表中可能出现暂时没有标题的条目。
- 回归应覆盖：有隐藏记录但目录为空、目录只含部分隐藏项、目录随后补齐标题、移除记录后恢复项归零。

## 核对入口

- `AndroidGatewayPreferences`、`AndroidSharedStateHolder` 的隐藏 / 恢复动作、会话抽屉与恢复对话框。
